# What counts as relevant

This applies only to blogs with `"filter": true` in `blogs.json` (company engineering blogs).
Posts from `"filter": false` blogs are always shown; for those, only tag the topics that fit.

I'm a backend engineer. Keep a post only when its main subject is one or more of:

- **ai** — engineering with AI: building on LLMs, agents, tool use, evals, prompting
  techniques, model training or inference infrastructure, ML systems, research results
  with technical substance.
- **backend** — backend and systems engineering: distributed systems, APIs, networking,
  performance, reliability, incidents and postmortems, infrastructure, deployment,
  server-side languages and runtimes, security engineering.
- **databases** — databases and data systems: storage engines, query processing, SQL,
  indexing, replication, transactions, data modeling, caching, streaming and pipelines.

Skip posts that are mainly company or funding news, partnerships, customer case studies,
hiring, events, policy or politics, pricing, marketing, or a product announcement with no
technical detail. Personal essays count only if they are substantially about one of the
three topics.

When a post is borderline, keep it only if an engineer would learn something technical from it.
